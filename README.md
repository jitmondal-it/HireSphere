# HireSphere - Full Stack Job Portal

HireSphere is a full-stack job portal application that connects job seekers with employers. It provides a modern, responsive interface for job searching and recruitment, with secure authentication and role-based access.

## Features

### For Job Seekers
- User Registration & Login
- Secure JWT Authentication
- Browse and Search Jobs
- Filter Jobs
- View Job Details
- Apply for Jobs
- Manage Profile

### For Employers
- Employer Registration & Login
- Post New Jobs
- Edit Job Listings
- Manage Posted Jobs
- View Applicants

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS
- Mantine UI
- React Router DOM
- Redux Toolkit
- Axios

### Backend
- Spring Boot
- Spring Security
- JWT Authentication
- MongoDB
- Maven

## Installation

### Frontend

```bash
git clone https://github.com/jitmondal-it/HireSphere-Frontend.git
cd HireSphere-Frontend
npm install
npm start
```

Frontend runs at:

```
http://localhost:5173
```

### Backend

```bash
git clone https://github.com/jitmondal-it/HireSphere-Backend.git
cd HireSphere-Backend
```

Configure MongoDB in `application.properties`, then run the Spring Boot application.

Backend runs at:

```
http://localhost:8081
```
